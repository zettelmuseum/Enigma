Quick and Dirty port of Enigma puzzle game 
for Android using current tools and sdk.

Stripped many things, all internet access,
editor, music, etc.

Tested, all levelpacks/levels are working (except a few 
tutorials)

Do not go deep into options, it may crash.

IMPORTANT:

Triple Tap = Use Inventory Item

4x Tap = Rotate Inventory Items

See Actions Workflow, apk in releases.

https://www.nongnu.org/enigma/index.html
